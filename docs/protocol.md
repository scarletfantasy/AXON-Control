# AXON 3 USB-MIDI 协议记录

本文件描述本项目实现的设备通信格式。内容基于协议观察与程序行为分析；没有包含原版程序、固件、反编译代码或真实用户抓包。例子是字段说明或合成数据，不是完整的官方规范。

## 传输与身份

通过 Windows WinMM 打开名称包含 `NUX AXON` 的 MIDI 输入与输出，动态获取端口编号，串行执行命令与确认。连接要求恰好一组匹配端口。

身份请求为 `F0 43 58 00 F7`；响应以 `F0 43 58 10` 开头，共 45 字节。在从零计数的字节 36–43 中验证零填充的 ASCII 模型标记 `NFM-3`。其他身份字段未完整解释，不把原始版本字段当作已确认的固件版本或序列号。

一般报文：

```text
F0 43 58 70 CMD MODE PAYLOAD F7
MODE: 00 查询 / 01 设置 / 02 查询响应 / 03 设置确认
```

数据区字节必须小于 `0x80`。已观察到的报文没有额外的校验和字段。

## 状态与预设命令

命令编号以下均为十六进制。

| CMD | 请求或设置 | 说明 |
| --- | --- | --- |
| `15` | 查询无载荷；设置 8 字节状态 | 预设选择、整体 EQ、保存与当前重置 |
| `0B` | 查询载荷为槽位 | 读取该槽位的已保存预设 |
| `0C` | 查询载荷为 `00` | 读取当前工作参数 |
| `0C` | 设置：频段、字段、6 字节编码值 | 修改单个参数 |
| `12` | 设置：槽位、14 字节 ASCII 名称 | 重命名，语义仍需实机确认 |
| `7B` | 设置载荷为 `01` | 重置全部，具体范围仍需实机确认 |

状态载荷由 8 字节构成：

| 字节 | 含义 |
| --- | --- |
| 0 | 预设数量 |
| 1 | 整体 EQ：1 启用、0 旁通 |
| 2 | 活动槽位，从 0 开始 |
| 3 | 重置当前的动作标记 |
| 4 | 保存工作参数的动作标记 |
| 5–7 | 含义未确认；新的设置载荷置零 |

动作标记不是持久配置。新建状态请求时仅启用本次动作，不能照搬读回值。保存后读取相应的已保存槽位确认；收到 ACK 并不足以证明保存内容正确。

已保存/工作参数响应分别为：

```text
F0 43 58 70 0B 02 SLOT <189 字节编码数据> F7
F0 43 58 70 0C 02 00   <189 字节编码数据> F7
```

## 七位传输编码

将每两个原始字节视作大端 16 位整数 `W`，输出三字节：

```text
A = W >> 14
B = (W >> 7) & 0x7F
C = W & 0x7F
W = (A << 14) | (B << 7) | C
```

`A` 必须在 0–3，`B/C` 在 0–127。126 字节预设编码为 189 字节。这仅是传输编码；内部参数数值使用小端格式。

## 预设数据结构

解码后的 126 字节：前 14 字节为零填充名称，随后 7 个 16 字节频段记录，顺序为 `HP LF LMF MF HMF HF LP`。

每段记录使用 Python 格式 `<HHfff`：

| 相对偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | uint16 | 启用状态，0 或 1 |
| 2 | uint16 | 未知/保留字段，原样保留 |
| 4 | float32 | 频率 Hz |
| 8 | float32 | Q |
| 12 | float32 | 增益 dB |

HP/LP 的 Q 与增益字段未确认可调整；界面只开放开关与频率，并保留另外两个字段。支持的输入范围为频率 20–20000 Hz、其余五段 Q 0.1–10、增益 −12 至 +12 dB。

单参数写入为：

```text
F0 43 58 70 0C 01 BAND FIELD <6 字节编码值> F7
FIELD: 0 开关/保留字；1 频率；2 Q；3 增益
```

开关字段传输原记录的前 4 字节，改变 uint16 开关并保留其后的 uint16。其余字段各传输对应的 4 字节 float32。单参数确认没有完整参数内容，必须读回核对。

## 事务行为

连接与刷新只读。写入前备份，并检查活动槽位以及工作参数是否仍与编辑基准一致。读快照期间再次核对槽位，避免把不同槽位的数据混在一起。

读取采用有上限的等待与重试；设置、保存、改名和重置不能因 ACK 超时而自动重复。部分参数写入失败时，仅在确认槽位仍一致的情况下尝试恢复已写字段。设备状态不明时停止操作，保留备份与本地草稿，要求重新读取。

## 尚未确认

- 固件是公版还是定制、源码与升级/签名格式。
- 实际 DSP 采样率、滤波器实现与所有隐藏参数。
- 命令 `07` 的作用；本项目不实现它。
- 整体 EQ、改名、重置的全部实机语义及其他型号兼容性。

界面响应曲线使用估计的 48 kHz 模型；它是编辑辅助，不是声学测量。实时频谱来自电脑播放端的回环信号，与设备内部音频观测接口无关。
